# 추천시스템 레포트 과제 — 추천 평가 (Evaluation)

데이터는 MovieLens 1M 평점 100 만 개를 정리한 movielens_1m_eval.csv(user_id, movie_id, rating, timestamp, split)를 사용한다. 
split 열은 각 유저의 평점을 timestamp순(같으면 movie_id 순)으로 정렬했을 때 마지막 10 개를 test, 나머지를 train 으로 표시한것이다. 
랭킹 평가에서 정답은 테스트 평점이 4 이상인 아이템이다.
모든 모델과 평가 지표는 Python(NumPy, pandas)으로 직접 구현한다. 
**scikit-learn 등 라이브러리의 평가 함수는 사용하지 않는다. 각 문제에 제시된 함수를 구현하고, 함수를 호출하여 결과를 출력하는 코드를 함께 제출한다.**


## 문제 1. 평가 프로토콜과 베이스라인

split 열로 학습·테스트 데이터를 나누고, 각각의 평점 수, 유저 수, 아이템 수를 출력하라.
학습 데이터로 아래 세 예측 모델을 만드는 함수 fit_baseline(train)과, 학습된 모델로 (user_id, movie_id) 쌍의 평점을 예측하는 함수 predict(model, df, kind)를 구현하라.
μ 는 학습 평점의 전체 평균, bᵢ 는 아이템 i 의 (r − μ) 평균, bᵤ 는 유저 u 의 (r − μ − bᵢ) 평균이며, 학습 데이터에 없는 유저·아이템의 편향은 0 으로 한다. 무작위 분할 대신 시간 기준으로 분할하는 이유를 설명하라.
- 모델 A: r̂ = μ
- 모델 B: r̂ = μ + bᵢ
- 모델 C: r̂ = μ + bᵤ + bᵢ


## 문제 2. RMSE 와 MAE

함수 rmse(y, y_hat)와 mae(y, y_hat)를 구현하라. 
세 모델의 테스트 RMSE(Root Mean Squared Error)와 MAE(Mean Absolute Error)를 표로 출력하고, 모델 B 대비 모델 C 의 RMSE 개선율(%)을 계산하라. 
두 지표의 차이가 무엇을 뜻하는지 설명하라.


## 문제 3. 마이크로 평균과 매크로 평균

함수 macro_rmse(df)를 구현하여 모델 C 의 테스트 RMSE 를 마이크로 평균(전체 테스트 평점 기준)과 매크로 평균(유저별 RMSE 의 평균)으로 각각 계산하라. 
- 마이크로: (u,i)공간에서 계산
- 매크로: u 공간에서 계산
유저를 학습 평점 수 기준 4 개 분위 그룹으로 나누어 그룹별 RMSE 를 막대그래프로 그리고, 두 평균의 차이를 그룹별 결과로 설명하라.


## 문제 4. 랭킹 지표

유저마다 학습 데이터에서 평가하지 않은 전체 아이템을 점수 순으로 정렬하여 Top-10 추천 목록을 만드는 함수 recommend(scores, seen, k)를 구현하라. 
추천 모델은 아래 두 가지이다. 
한 유저의 추천 목록과 정답을 입력받는 함수 precision_at_k, recall_at_k, reciprocal_rank, average_precision_at_k, ndcg_at_k 를 구현하라. 
테스트 정답이 1 개 이상인 유저에 대해 Precision@10, Recall@10, F1, MRR(Mean Reciprocal Rank), MAP@10(Mean Average Precision), NDCG@10(Normalized Discounted Cumulative Gain)을 유저 평균으로 계산하여 표로 출력하라. 
NDCG 의 관련도는 정답 아이템의 테스트 평점, 그 외 아이템은 0 으로 한다. 
문제 2 의 결과와 비교하여 설명하라.
- 인기 추천: 학습 데이터의 평점 수
- 모델 C 추천: 모델 C 의 예측 평점


## 문제 5. 표본 채점 (Sampled Metrics)

문제 4 의 유저마다, 테스트 정답 중 평점이 가장 높은 아이템 1 개(동점이면 timestamp 가 가장 늦은 아이템, 그래도 같으면 movie_id 가 가장 작은 아이템)와 그 유저가 학습·테스트 데이터에서 평가하지 않은 아이템 99 개로 100 개 후보를 구성하는 함수 sample_candidates(user, rng)를 구현하라. 
99 개는 np.random.default_rng(42)로 유저 ID 오름차순으로 추출한다. 
두 추천 모델로 100 개 후보를 정렬하여 문제 4 의 함수로 Recall@10 과 NDCG@10(정답 관련도 1)을 계산하고, 문제 4 의 전체 랭킹 결과와 비교하여 설명하라.
