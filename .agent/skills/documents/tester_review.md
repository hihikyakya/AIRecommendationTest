# Tester 검증 결과: 재작성본 과제 명세 대조

검증 기준: `.agent/skills/documents/추천시스템_레포트_과제.md` 문제 1~5
검증 대상: 재작성 후 현재 작업 트리

## 명세 대조 결과

- 문제 1: 요구한 split별 요약, μ·bᵢ·bᵤ 공식, 미관측 편향 0, A/B/C 예측, 시간 분할 설명을 구현했다.
- 문제 2: NumPy로 RMSE·MAE를 계산하고 세 모델 표, B 대비 C 개선율, 두 지표 설명을 출력한다.
- 문제 3: 마이크로/매크로 RMSE와 학습 평점 수 기준 4분위별 RMSE를 계산한다. 재작성본은 Jensen 부등식 방향과 동일한 테스트 평점 수 조건을 올바르게 설명하며, 비활성 유저에 관한 기존 문구를 제거했다. matplotlib 막대그래프도 `outputs/problem3_group_rmse.png`에 저장된다.
- 문제 4: train에서 본 아이템 제외 Top-10, 인기 점수와 모델 C 예측 점수 기반 추천, 유저 평균 랭킹 지표 및 문제 2 비교 설명을 구현했다. 모델 C는 한 유저의 아이템 간 순위가 bᵢ 정렬과 일치한다.
- 문제 5: 평점/timestamp/movie_id 동점 규칙, 유저 ID 오름차순 단일 seed RNG 추출, 전체 평가 아이템 제외 99개 샘플, 후보별 Recall@10 및 관련도 1의 NDCG@10을 구현했다.

문제 3의 정량 결과는 Q1 0.9940, Q2 0.9586, Q3 0.9489, Q4 0.9166이고, 마이크로 0.9550 ≥ 매크로 0.9044다. Jensen 방향은 이제 맞다. 단, “Q1의 큰 오차 분산이 Jensen gap의 핵심 요인”이라는 인과 주장은 현재 출력된 분위별 평균 RMSE만으로 직접 입증되지는 않는다. 유저별 MSE 분산을 추가 계산하거나, 해당 문장을 관찰된 분위별 추세에 한정해 표현하면 엄밀하다. 이는 계산/명세 구현 실패는 아니다.

## 판단

이전 검토에서 발견한 문제 3의 수학적 오류와 그래프 미구현은 해결됐다. 현재는 과제 명세의 핵심 요구를 충족해 커밋 가능한 상태다. 위 Jensen gap 원인 문구를 더 엄밀하게 다듬는 것은 권장 사항이다.
